# STM32H7Pxx AddOn for Keil uVision V5.43

Keil uVision is the reference integrated development environment for this AddOn. Additional details regarding Keil uVision are available at [arm.com](https://support.arm.com/tools-and-software/keil-mdk).

## Overview

This document outlines the procedure required to extend an existing Keil uVision installation with STM32H7Pxx device support. The patch is applicable to Keil uVision version 5.43.

## Prerequisites

- A working installation of **Keil uVision** version 5.43.
- Permissions to modify files inside the Keil uVision installation directory (administrator/root rights may be required).

## Installation steps

1. Extract `MDK543a-AddOn_STM32H7Pxx.zip`
2. Run the extracted `MDK543a-AddOn_STM32H7Pxx.exe` executable with required rights to modify the existing Keil uVision installation
3. Follow the on-screen instructions provided by the installer to complete the AddOn installation.\
   Select the installation directory corresponding to your Keil uVision installation (e.g., `C:\Keil_v5`)
